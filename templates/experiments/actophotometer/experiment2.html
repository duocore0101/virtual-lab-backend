Procedure (Step-by-Step)

1. Animal Selection and Grouping:

  • Select healthy mice (20-30 g).
  • Divide into 3 groups (n=4-6 each): Control (saline), Standard (known depressant/stimulant), Test (drug under evaluation).

2. Instrument Setup:

  • Switch on the actophotometer. Ensure no obstacles block beams.
  • Reset counter to zero before each reading.

3. Acclimatization:

Allow mice to habituate to lab environment (quiet, dim light) for 30-60 min.

4. Pre-Drug (Basal) Activity Recording:

  • Weigh and mark each mouse. Place individually in the actophotometer cage.
  • Record basal locomotor scores (beam interruptions) for 5-10 minutes.

5. Drug Administration:

  • Inject i.p. (volume ~0.1-0.3 mL): Control (Saline), Depressant (Chlorpromazine), Stimulant (Caffeine/amphetamine).

6. Post-Drug Activity Recording:

  • Wait for peak effect (~30 min). Place each mouse back in the cage.
  • Record post-drug scores for 5-10 minutes.
