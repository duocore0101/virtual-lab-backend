{% load static %} Pharmacokinetic Parameters – Requirements
Aim: To calculate key pharmacokinetic (PK) parameters such as Cmax, Tmax, Half-life (t1/2), AUC, Clearance and Volume of Distribution from given plasma concentration–time data.

Requirements / Materials

Data Provided

  • Given plasma concentration–time data table
  • Time (hours) vs Plasma drug concentration (µg/mL)
  • Data covering absorption and elimination phases

Graphing Materials

  • Semi-log graph paper (or Excel / Google Sheets)
  • Ruler, pencil and eraser
  • Proper scale selection for accurate plotting

Calculation Tools

  • Scientific calculator / calculator app
  • Logarithm function (log / ln)
  • Formula sheet for PK parameter calculations

Reference Material

  • Pharmacokinetic equations (Cmax, Tmax, t1/2)
  • Trapezoidal rule formula for AUC calculation
  • Clearance and Volume of Distribution formulas
