📋 Step-by-Step Procedure

  1. Data Tabulation: Review the provided plasma concentration–time data ($IV$ bolus administration).
  2. Graph Plotting: Plot the data on a semi-logarithmic scale ($Time$ on linear X-axis, $Concentration$ on logarithmic Y-axis).
  3. Curve Analysis: Identify the terminal elimination phase and draw a best-fit straight line.
  4. Extrapolation: Extrapolate the terminal line back to $Time = 0$ to obtain the intercept ($C₀$).
  5. Kel Calculation: Calculate the slope of the line. The elimination rate constant ($Kₑₗ$) is equal to $(-2.303 \times \text{Slope})$.
  6. Parameter Estimation:
    • Half-life ($t_{1/2}$): $0.693 / Kₑₗ$
    • Volume of Distribution ($Vd$): $Dose / C₀$
    • Clearance ($Cl$): $Kₑₗ \times Vd$
    • AUC ($0 \rightarrow \infty$): $C₀ / Kₑₗ$

📐 Technical Formulas & Sample

Sample Values (Dose = 500 mg):
• C₀ = 25 mg/L (from intercept)
• Slope = (log C₁ - log C₂) / (T₁ - T₂)
• Kₑₗ = 0.300 h⁻¹
• t₁/₂ = 0.693 / 0.300 = 2.31 h
• Vd = 500 / 25 = 20 L
• AUC (0-∞) = 25 / 0.300 = 83.33 mg·h/L
• Clearance = 0.300 × 20 = 6 L/h
